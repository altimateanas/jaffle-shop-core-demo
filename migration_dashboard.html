⚠ Critical Migration Gotchas
These 4 issues cause silent data errors — review carefully
🔴 array_contains — ARGUMENT ORDER REVERSED
Databricks: array_contains(array, value)
Snowflake: ARRAY_CONTAINS(value, array) ← args swapped!
🔴 dayofweek — OFFSET DIFFERENCE
Databricks: dayofweek() → 1=Sunday
Snowflake: DAYOFWEEK() → 0=Sunday · fix: DAYOFWEEK()+1
🟡 datediff — ARG ORDER DIFFERENT
Databricks: datediff(day, start, end)
Snowflake: DATEDIFF('day', start, end) — same order but date_part must be quoted
🟡 FILTER clause — NOT NATIVELY SUPPORTED
Databricks: COUNT(*) FILTER (WHERE amount > 50)
Snowflake: SUM(CASE WHEN amount > 50 THEN 1 ELSE 0 END)
